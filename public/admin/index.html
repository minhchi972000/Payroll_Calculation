1. Chọn kỳ lương và nguồn dữ liệu

Chưa chọn file

Chưa cấu hình Google service account. Xem mục “Google Sheet” trong README để bật tính năng này, hoặc tải Google Sheet về dạng .xlsx (Tệp → Tải xuống) rồi dùng tuỳ chọn File Excel.

Share Google Sheet (quyền Người xem) cho email:

File cần có một dòng tiêu đề, trong đó có cột Số CCCD (bắt buộc, đủ 12 số) và Họ tên. Nhân viên đăng nhập bằng số CCCD. Mọi cột còn lại sẽ hiện cho nhân viên, trừ cột “STT” và cột có tiêu đề bắt đầu bằng # (cột nội bộ). Tải file mẫu bảng lương (.xlsx)
